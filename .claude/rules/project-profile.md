# 프로젝트 프로필

이 프로젝트에만 해당하는 내용은 모두 이 파일에 둔다. 에이전트와 스킬은 아래 **섹션 이름**으로 이 파일을 참조하므로 섹션 이름을 바꾸지 않는다.

`<미입력>`이 남은 항목은 `/init-harness`가 채운다. `<미입력>`이 남아 있으면 `/plan`과 `/dev`는 시작하지 않는다.

## 스택

- 서버: Spring Boot <미입력: 버전>, Java <미입력: 버전>, 빌드 도구 <미입력: Gradle | Maven>
- 데이터 접근: <미입력: JPA | MyBatis | 직접 SQL | 혼용>
- DBMS: <미입력: 종류와 버전>
- 마이그레이션: <미입력: Flyway | Liquibase | 수동 SQL | 없음>
- 화면: <미입력: 프레임워크와 버전, 서버 렌더링 템플릿, 또는 "없음">
- E2E: Playwright (고정)

## 명령

저장소 루트에서 그대로 실행할 수 있는 형태로 적는다.

- 빌드: `<미입력>`
- 전체 테스트: `<미입력>`
- 단일 테스트: `<미입력>`
- 서버 기동(로컬): `<미입력>`
- 화면 빌드·린트: `<미입력 또는 "없음">`
- E2E 실행: `<미입력>` (기본: `cd e2e && npx playwright test`)
- E2E 단일 파일: `<미입력>` (기본: `cd e2e && npx playwright test tests/<파일>`)

## 디렉터리

- 컨트롤러: `<미입력>`
- 서비스: `<미입력>`
- 리포지토리·매퍼: `<미입력>`
- 엔티티·도메인: `<미입력>`
- 마이그레이션: `<미입력 또는 "없음">`
- 화면 코드: `<미입력 또는 "없음">`
- 단위·통합 테스트: `<미입력>`
- E2E: `e2e/`

## DB 접속

`db-helper`가 이 섹션의 방법으로만 접속한다. 비밀번호는 적지 않는다(환경 변수 이름이나 접속 스크립트 경로만).

- 개발 DB 접속 방법: <미입력: 명령 또는 스크립트 사용법, 또는 "접속 없음">
- 접속 계정 권한: <미입력: SELECT 전용 | 쓰기 가능>
- 운영 DB: 접속하지 않는다 <바꾸려면 여기에 명시>

읽기 전용은 계정 권한으로 보장한다. 쿼리 문자열을 검사하는 방식에 기대지 않는다(HARNESS.md 9.2).

## 재사용 우선 대상

새 코드를 쓰기 전에 여기서 먼저 찾는다. `refactoring-specialist`가 재사용 누락을 이 목록으로 판단한다.

- <미입력: 경로 — 무엇을 하는가>

## 리뷰 체크리스트

웹 기본 체크리스트(`code-reviewer`)에 더해 이 프로젝트에서만 보는 것. 과거에 실제로 문제가 됐던 것 위주로 적는다.

- <미입력 또는 "없음">

- <미입력 또는 "없음">
